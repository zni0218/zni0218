##  Projetos e áreas de trabalho

###  Deteção de ficheiros duplicados multimédia
Desenvolvimento de ferramentas em Python para identificar ficheiros iguais ou semelhantes, recorrendo a técnicas diferentes consoante o tipo de conteúdo. Entre as abordagens exploradas estão hashes criptográficos, comparação por blocos, hashes percetuais para imagens e vídeo, comparação de texto e características de áudio.

**Tecnologias e conceitos:** Python, SHA-256, análise de similaridade, processamento de imagem, áudio e vídeo.

###  Geração de mapas para Webots
Ferramentas para gerar mapas de simulação a partir de ficheiros de configuração YAML e imagens, associando cores a elementos do ambiente, como paredes, lugares de estacionamento e obstáculos.

**Tecnologias e conceitos:** Python, YAML, NumPy, Pillow e Webots.

###  Análise e processamento de dados
Projetos e exercícios de análise de dados, transformação de ficheiros e exploração de conjuntos de dados, com atenção à organização, eficiência e escolha das ferramentas adequadas a cada problema.
